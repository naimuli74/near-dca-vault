Cross-chain DCA, without a custodian.

Deposit USDC from any chain NEAR Intents supports, pick BTC, ETH or NEAR, and a schedule. Each buy is a real 1Click quote. Dry-run is the default: judges can try it with no funds. Live mode is opt-in, and you send each interval yourself to a fresh deposit address.

Start a dry-run → How it works
  • Real 1Click quotes
  • Dry-run by default
  • No custody, no keys
1

Create a plan

Choose USDC on a supported chain, a target asset, a destination address, a size, a slippage limit and a schedule.

2

Get a real quote

Each interval asks 1Click for a quote. Dry-run stops there. If the price is worse than your limit after fees, the buy is skipped.

3

You send, if you want

In live mode you fund that interval's deposit address yourself. The asset lands in your own address. We never hold the funds.

New plan

Dry-run fetches real quotes and writes them to history. Nothing is deposited.
Live mode is mainnet. The app will request a real 1Click deposit address. You send the funds yourself. There is no Intents testnet. Use a small amount, and only an address you control.

Quote preview

Press Preview quote for a live dry quote from the 1Click API. No deposit address is created.

1Click deposit addresses are unique and expire in about 10 minutes, so this app does not hold a standing vault. A future version could let a NEAR contract own the funds and use Chain Signatures to pay each interval. Read the limits.
